# assets/music —— 音乐文件放这里

**当前音乐栏目是空的**，页面显示「敬请期待」。
想开启这个栏目，需要两步：

## 第 1 步：把 mp3 放进这个目录

## 第 2 步：在 `js/data.js` 里填曲目信息

找到 `const TRACKS = [];`，改成：

```js
const TRACKS = [
  {
    title: '花谱',                          // 曲名
    artist: 'SilentForge Sound',            // 作者
    album: '百合花 Original Soundtrack',    // 专辑
    duration: '—',                          // 留 '—' 会自动读真实时长
    file: 'assets/music/huapu.mp3',         // 文件路径（对上文件名）
    cover: 'assets/img/icon.png',           // 封面图
    tags: ['主题曲', '钢琴'],                // 标签
  },
  // 想加更多就继续往下写
];
```

保存刷新，播放器就出现了。

## 说明

- **文件名要对上。** `file` 写什么，磁盘上就得有那个文件。
- **缺文件也不会报错。** 播放器找不到音频时会自动切换到内置合成器，
  生成一段演示旋律并提示路径，所以栏目不会白屏。
  放入真实 mp3 后刷新，就自动播放真曲，列表里也会显示真实时长。
- 格式支持 mp3 / m4a / ogg / wav，其中 **mp3 兼容性最好**。
- 想彻底关闭这个栏目，保持 `TRACKS` 为空数组即可，页面会显示「敬请期待」。
